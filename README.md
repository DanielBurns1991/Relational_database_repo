# Module 14.1 & 14.2 - Level 7 Apprenticeship in Data and AI

## Overview
This repository contains the work completed for **Module 14.1** and **Module 14.2** of the **Level 7 Apprenticeship in Data and AI**. The focus of these modules is on applying data science and AI techniques to real-world problems, with an emphasis on practical implementation and analysis.

## Project Structure
- **`data/`**: Contains datasets used for analysis and model training.
- **`notebooks/`**: Jupyter Notebooks for exploratory data analysis, model development, and results visualization.
- **`scripts/`**: Python scripts for data preprocessing, model training, and evaluation.
- **`results/`**: Output files such as model summaries, plots, and reports.
- **`reports/`**: Final reports and documentation related to the project.

## Technologies Used
- **Python**: For data analysis, machine learning, and scripting.
- **Jupyter Notebook**: For exploratory data analysis and visualization.
- **Pandas & NumPy**: For data manipulation and analysis.
- **Scikit-learn & TensorFlow**: For machine learning and deep learning tasks.
- **Matplotlib & Seaborn**: For data visualization.
- **Git & GitHub**: For version control and collaboration.
